# Legacy layout / 旧版布局

The inherited multilingual README files and the original `schemas/style-v2.1.schema.json`
are intentionally not duplicated in the OhMyStyle root. The current entry point is
the bilingual [root README](../README.md), and the canonical schemas live in
[`schema/`](../schema/).

位于 [`schema/`](../schema/)。原始项目的归属和许可证边界仍见 [NOTICE](../NOTICE)。
