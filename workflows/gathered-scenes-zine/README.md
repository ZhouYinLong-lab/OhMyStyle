# 场景聚合杂志

## 这是什么

这是一个把照片转化为杂志式场景作品的工作流。它提供两个明确变体：

- **保留照片**：照片继续作为真实锚点，再用抽象形状、结构性色块和纸张层次组织版面。
- **场景提炼**：不保留原照片像素，只提取场景的语义核心、情绪张力和视觉隐喻，重新组织成纸面作品。

两种变体都从用户输入开始。它们不规定默认地点、人物、故事或固定物件；同一个工作流可以处理厨房、街道、海岸、室内或抽象物件。

## 处理逻辑

观察输入，区分事实与感受；减少无关细节；把空间、颜色、方向和情绪转译成纸面元素；最后通过版式、留白和表面层次完成编排。

选择“场景提炼”时，输出是基于输入场景的再创作，不应被描述为原照片的直接记录。选择“保留照片”时，照片主体和事实关系优先于装饰性扩展。

## 使用方式

1. **交给有生图能力的 Agent**：把本目录、照片和变体选择交给 Agent，让它先阅读 `workflow.yaml`，再生成一版可检查的任务说明。
2. **复制生成 Prompt**：把所选变体的 `purpose`、工作流步骤和保护条件整理到 Prompt，主题由你提供，不能照抄示例题材。
3. **配置 API Key 一键生成**：把工作流交给支持图像输入的 Agent，配置你自己的 API Key；如需风格语言，再附加一个独立风格包。
4. **本地模型 + ComfyUI**：保留照片变体使用图像输入和版式节点；场景提炼变体使用参考图与重绘节点，但保留“不得固定题材”的文本约束。

生成前确认照片的使用权。生成后检查主体独立性、变体是否执行正确、是否出现未请求的地点或物件，以及纸面元素是否仍与输入有可说明的关系。
