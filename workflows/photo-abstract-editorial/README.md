# 摄影抽象编辑

## 这是什么

这是一个“照片保留 + 抽象编辑”的创作工作流。它把输入照片当作主要事实来源：照片区域继续承担人物、建筑、景物和空间信息，旁边或下方的抽象区域只提取照片中的方向、色彩、尺度和结构关系。

它不是一个固定题材模板，也不是一套默认的海报风格。输入可以是人物、物件、建筑或自然场景，结果应随输入变化。

## 处理逻辑

1. 先观察照片中真实存在的主体、空间层次和主要色彩。
2. 保留清晰的照片区域，不替换原主体身份。
3. 把可观察的空间关系转译为少量抽象色块、线条或平面区域。
4. 用留白和版式把两部分组织成编辑作品；标题和文字是可选层。

工作流允许改变构图、色彩关系、表面和排版层级；输入主体、用户约束和照片事实受到保护。它不会因为示例使用过某个地点，就在每次生成中加入同一地点。

## 使用方式

1. **交给有生图能力的 Agent**：把本目录和你的照片交给 Agent，说明你想保留哪些照片事实、需要什么画幅和是否加入文字。
2. **复制生成 Prompt**：读取 `workflow.yaml`，将 `purpose`、`allowed_axes` 和保护条件复制到 Prompt，只替换自己的主题与版式要求。
3. **配置 API Key 一键生成**：使用支持图像输入的 Agent 或平台，配置你自己的 API Key，让 Agent 先读取本工作流，再提交生成任务。
4. **本地模型 + ComfyUI**：将原图作为输入，分别接入版式、抽象区域和输出尺寸节点；不要用风格节点覆盖原图主体。

生成前确认照片的使用权。生成后检查：原主体是否仍可辨认、抽象元素是否能在照片中找到依据、是否出现未请求的固定物件。
