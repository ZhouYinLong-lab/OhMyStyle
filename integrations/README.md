# 外部创作工作流登记

这里登记与 OhMyStyle 兼容的外部创作工作流。登记不是收录，也不是再分发：本目录只保存来源链接、许可证链接、兼容协议和边界说明，不复制外部仓库的 Skill、Prompt、示例图、数据或品牌素材。

## 摄影抽象编辑

来源：[ZzzLc0405/photo-abstract-editorial](https://github.com/ZzzLc0405/photo-abstract-editorial)

OhMyStyle 对应协议：[摄影抽象编辑工作流](../workflows/photo-abstract-editorial/README.md)

外部项目的核心方向是保留输入照片的事实锚点，再从照片的空间和色彩关系中组织抽象编辑区域。完整外部内容受作者仓库中的[自定义非商业许可证](https://github.com/ZzzLc0405/photo-abstract-editorial/blob/main/LICENSE.md)约束，使用者应自行阅读并取得必要许可。

## 场景聚合杂志

来源：[Zeejay0/gathered-scenes-zine-skill](https://github.com/Zeejay0/gathered-scenes-zine-skill)

OhMyStyle 对应协议：[场景聚合杂志工作流](../workflows/gathered-scenes-zine/README.md)
