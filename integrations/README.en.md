# External creative workflow registry

This directory records external creative workflows that can work with OhMyStyle. A registry entry is not a collection or a redistribution: it stores source links, license links, compatibility contracts, and boundaries. It does not copy upstream skills, prompts, examples, data, or brand assets.

- Obtain a complete upstream skill from its original repository.
- The workflow files in OhMyStyle are independently authored compatibility layers, not reposted upstream files.
- Listing an external project does not change its license to the OhMyStyle license.
- The user is responsible for the rights, privacy, likeness permissions, and generation-platform terms for input photos.
