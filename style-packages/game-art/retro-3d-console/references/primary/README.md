# 主要参考 / Primary reference

科学博物馆集团：[Sony Playstation and video games](https://collection.sciencemuseumgroup.org.uk/objects/co8194708)

该馆藏记录用于确认早期家用主机三维图形转型的历史背景。本包提取低多边形、低分辨率纹理和实时空间限制等可观察方向，不捆绑游戏截图或品牌资产。

This collection record provides historical context for the shift toward early home-console 3D graphics. The package extracts observable constraints such as low polygon budgets, low-resolution textures, and real-time spatial rendering; it does not bundle game screenshots or branded assets.
