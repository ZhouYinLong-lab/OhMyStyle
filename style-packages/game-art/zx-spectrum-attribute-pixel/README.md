# ZX Spectrum Attribute Pixel Art — game-art demo

This package adds the first game-art direction to OhMyStyle. It is intentionally
technical rather than mood-only: the image must obey a 256×192 raster logic,
8×8 attribute cells, and a two-color-per-cell constraint. These limits are the
style, not merely post-processing decoration.

The sample prompt is anonymous and does not mention a particular game, studio,
character, or copyrighted screen.
