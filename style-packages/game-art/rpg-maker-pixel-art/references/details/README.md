# Reference analysis

The reference set was obtained from official Steam screenshot endpoints and
inspected locally before the style signature was written. The images remain
outside the repository because the game screenshots are commercial copyrighted
assets. `manifest.csv` records their URLs and the no-redistribution policy.

Shared observations:

- authored low-resolution pixel clusters rather than a smooth image with a pixel filter;
- small characters and objects whose scale supports the environment;
- tile-based rooms and landscapes organized by readable planes;
- warm windows or sunset against cool night water sky or shadow;
- sparse props and negative space used for composition;
- background detail that becomes broader and less literal with distance.

Variation observations:

- To the Moon provides open outdoor spaces reflective skies and soft warm-cool transitions.
- Impostor Factory provides enclosed top-down geometry deeper shadow pools and occasional unusual forms.
