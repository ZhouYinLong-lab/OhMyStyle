# RPG Maker Pixel Art — game-art demo

This package models a broad 2D tile-based pixel-game direction. To the Moon
and Impostor Factory are reference examples, not names to paste into a
generation prompt and not assets to reproduce.

The package is subject-neutral. It can compile exploration, dialogue, puzzle,
combat, title, transition, room, landscape, or environmental scenes. Open
outdoor spaces and enclosed interiors are optional variants rather than
requirements.

Commercial screenshots were inspected before curation but are not
redistributed. See `references/manifest.csv` and `provenance.yaml` for source
and attribution information. The generated example is independently authored
and approved for this repository.
