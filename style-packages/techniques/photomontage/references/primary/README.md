# 主要参考 / Primary reference

东京写真美术馆：[The Great Wave, Sete, 1856/59](https://museumcollection.tokyo/en/works/6259126/)

馆藏说明区分了摄影蒙太奇与一般拼贴，并提到重叠负片、暗房遮罩和多重曝光等技术线索。本包只提取技术特征，不捆绑馆藏图像。

The collection record distinguishes photographic montage from general collage and discusses overlapping negatives, darkroom masking, and multiple exposure. This package extracts technical traits only and does not bundle the collection image.
