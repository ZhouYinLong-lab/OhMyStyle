## Overview

## Curatorial note

明胶银盐印相不是一种题材风格，而是一套会改变观看感受的材料过程：纸、明胶、银盐和化学浴共同决定黑白照片的密度、颗粒和光泽。这个包适合把任何主体转成可信的黑白暗房印相，不会自动加入老相机、街道或怀旧故事。

## Subject independence

This package controls how an image is generated, not what it depicts. People, objects, places, architecture, plants, vehicles, and narrative come from the user's prompt. The representative image is only a demonstration and must not become a default subject.

## Visual signature

- 主体结构由阶调而非色相承担
- 中性黑白为主
- controlled photographic light translated into a full neutral value range
- fine grain, baryta-paper or fiber-paper impression, and restrained photographic sheen
