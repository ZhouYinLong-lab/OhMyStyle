## 简介

马丁·帕尔常把镜头放得很近，用直接闪光、鲜明色彩、局部裁切和普通物件之间的关系观察社会生活。画面里的幽默通常来自一个动作、一种姿态和一个背景细节碰巧并置，而不是来自摆拍或说明文字。这个包提取这种贴近日常的观察方法，不把泳池、海滩、游客或食物写成默认题材。

## 策展短评

我喜欢帕尔式照片里那种“生活自己露出一点破绽”的瞬间。它不需要宏大的事件，塑料椅、湿毛巾、半截身体和一束直光就能组成很具体的社会切片。使用时要尊重人物和隐私，尽量让尴尬来自构图关系，而不是把某个人变成笑话；这样画面才会有观察力，也有温度。

## 主体独立性

本包只决定观察距离、直接光线、色彩饱和度、裁切和日常细节关系，不规定人物、泳池、海滩、度假地、食物或事件。代表图中的公共泳池只是测试主体，新的生成应以用户需求为准。

## 来源与版权

研究入口为[马丁·帕尔官方网站介绍](https://martinparr.com/introduction/)和[个人履历](https://martinparr.com/cv/)。仓库不打包外部作品；代表图是新的匿名场景，不是具体摄影作品，也不表示合作、授权或背书关系。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录交给 Agent，让它先读取 `identity.yaml`、`visual-signature.yaml`、`reproduction.yaml`、`prompts/`、`palette/palette.json` 和 `evaluation.yaml`，再编译你的主体、画幅和用途。生成后检查观察距离、人物匿名性、现场色彩和裁切关系。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换 `{{SUBJECT}}`、`{{ASPECT_RATIO}}` 和 `{{USE_CASE}}`；把 `prompts/negative.txt` 一并提交给支持负面 Prompt 的平台。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，提交基础 Prompt、负面约束和调色板。本仓库不托管密钥或在线生图服务。

### 方式四：本地模型 + ComfyUI

将 Prompt、调色板和复现说明接入本地模型或 ComfyUI，生成后用 `evaluation.yaml` 复核，不要把代表图的泳池当成默认主体。
