## Overview

This package turns the slow looking of large-format black-and-white photography, deep open grayscale, natural light, and damp paper character into transferable visual rules. The package does not decide the people, place, or story.

## Curatorial note

Its strength is not making an image look old. It lets time remain in the gaps between tones: highlights carry air, shadows carry weight, and the subject keeps some space that does not need an explanation. Replace the example with a chair, building, or ordinary ground and the same viewing distance should still be present.

## Subject independence

This package controls visual treatment, not subject matter. The example’s people, family setting, southern landscape, and wet-process context are not default requirements.

## Use only this package

1. **Image-capable Agent:** upload this directory. Ask the Agent to read the rules, compile your subject first, generate, and review against `evaluation.yaml`.
2. **Copy the prompts:** replace subject, location, aspect ratio, and purpose in `prompts/base.txt`, then submit `prompts/negative.txt`.
3. **Use your own API:** configure your own API key and submit the prompt, negative constraints, palette, and reference links. Keep the key yourself.
4. **Local model and ComfyUI:** connect the prompts, use the reproduction notes for grayscale, paper, and light, then review with the evaluation file.

References are for observable traits only. Do not copy a source work’s composition, figures, text, trademark, or logo.
