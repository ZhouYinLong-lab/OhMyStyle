## 简介

南·戈尔丁的私人纪实摄影把相机放进关系现场：距离很近，闪光灯直接，环境光不必被整理干净，颜色和生活痕迹一起留下。本包提取的是亲密观察、混合光和未经修饰的瞬间，不把夜店、裸露、药物或某段私人关系写成默认内容。

## 策展短评

我喜欢它的诚实感：画面不努力把生活变成“好看的故事”，而是让房间、皮肤、家具和光线共同保留当下的温度。它适合需要关系感和真实距离的场景，但使用时要给主体留出尊重和边界，不要用敏感题材替代视觉方法。

## 主体独立性

本包只决定观察距离、闪光和色彩，不决定人物身份、关系、地点或事件。示例中的匿名室内人物只是测试主体，新的生成可以是静物、建筑或任何用户指定的场景。

## 使用前先看

- `identity.yaml`：范围与排除项
- `visual-signature.yaml`：距离、闪光、色彩和表面特征
- `reproduction.yaml`：摄影构建顺序
- `prompts/base.txt`、`prompts/negative.txt`：基础 Prompt 与负面约束
- `palette/palette.json`：色彩角色
- `evaluation.yaml`：生成后检查项

## 来源与版权

本包参考惠特尼美国艺术博物馆的艺术家资料。外部照片、人物肖像、商标和网页内容仍归原权利人所有；仓库只保存来源链接和原创匿名示例，不打包外部作品。

## 只使用此包

1. 把本目录交给有生图能力的 Agent，要求它先读规则、Prompt、调色板和评价文件，再编译你的主体。
2. 复制 `prompts/base.txt`，替换主体、地点和画幅，并按需使用 `prompts/negative.txt`。
3. 在自己的生图平台配置 API Key，提交 Prompt、调色板和约束；本仓库不托管在线服务。
4. 接入本地模型或 ComfyUI，生成后用 `evaluation.yaml` 检查亲密感是否来自光线和取景，而不是固定敏感题材。
