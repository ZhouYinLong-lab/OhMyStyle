## Overview

This package places the camera inside a relationship or lived environment: close
distance, direct flash, mixed ambient light, saturated color, and surfaces that
are not cleaned into advertising. It does not make a nightclub, nudity, drugs, or
a named private relationship the default content.

## Curatorial note

The value is its honesty. The room, skin, furniture, and light are allowed to keep
the temperature of the moment instead of becoming a neat story. Use it when a
scene needs real proximity and trust, while keeping the subject's boundaries and
not substituting sensitive material for the visual method.

## Subject independence

This package controls distance, flash, and color, not identity, relationship,
place, or event. The anonymous interior figure is only a benchmark subject; your
prompt may define a still life, building, or any other scene.

## Sources and rights

The Whitney Museum of American Art artist page is used as a research source.
External photographs, portraits, trademarks, and web content remain with their
rights holders. This repository stores a source link and an original anonymous
demonstration only.

## Use only this package

1. Give the directory to an image-capable Agent and ask it to read the package
   rules before compiling your subject.
2. Copy `prompts/base.txt`, replace the subject, location, and aspect ratio, and
   use `prompts/negative.txt` when supported.
3. Submit the prompt, palette, and constraints through your own API tool after
   configuring your key; the repository does not host generation.
4. Connect it to a local model or ComfyUI workflow and review the result against
   `evaluation.yaml`.
