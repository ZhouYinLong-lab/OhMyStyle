## 简介

罗伯特·弗兰克的纪实摄影不急着把现场整理成漂亮答案。偏斜、裁切、反光、曝光不均和普通环境共同组成一种开放的观察方式；人物并不总是画面唯一的中心，照片更像一组更大序列中的片段。本包提取这种取景和观看方法，不固定公路、国旗、汽车或某个国家。

## 策展短评

我喜欢它对“完整画面”的克制：照片故意留下没有解释的部分，观者只能从一个角落、一块反光或一个被截断的人影里推测现场。用这个包时，普通地点往往比壮观景色更有效，关键是不要把偶然感修饰得太干净。

## 主体独立性

本包只决定观看方式，不决定人物、地点、物件或事件。示例中的路边服务区只是测试空间；新的生成可以从一把椅子、一座建筑或一件衣物开始。

## 使用前先看

- `identity.yaml`：范围与排除项
- `visual-signature.yaml`：取景、光线、色调和表面特征
- `reproduction.yaml`：摄影与冲印方向
- `prompts/base.txt`、`prompts/negative.txt`：基础 Prompt 与负面约束
- `palette/palette.json`：黑白色阶角色
- `evaluation.yaml`：生成后检查项

## 来源与版权

本包参考大都会博物馆的罗伯特·弗兰克展览资料。外部照片、人物肖像、商标和网页内容仍归原权利人所有；仓库只保存来源链接和原创匿名示例。

## 只使用此包

1. 把本目录交给有生图能力的 Agent，要求先读取全部规则文件，再编译你的主体与场景。
2. 复制 `prompts/base.txt`，替换主体、地点和画幅，并按需附上 `prompts/negative.txt`。
3. 在自己的生图平台配置 API Key，提交 Prompt、色阶和约束；本仓库不托管生成服务。
4. 接入本地模型或 ComfyUI，生成后用 `evaluation.yaml` 检查取景是否仍然开放、主体是否独立。
