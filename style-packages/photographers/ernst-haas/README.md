## 简介

恩斯特·哈斯把彩色胶片带进了纪实摄影的核心位置。颜色在他的画面里不只是装饰，也会参与速度、距离、反射和观看方向。清晰的形体可以和拖影并置，城市或日常场景因此获得接近绘画的节奏，却仍保留偶然观察的真实感。

## 策展短评

我喜欢这个包里“看见正在发生的时间”的感觉。它不急着把每个细节都解释清楚，而是让一块稳定的颜色、一处反射或一条运动方向把画面钉住。使用时可以先把主体说得很具体，再让模糊只发生在运动或观看距离上。

## 主体独立性

本包只决定彩色胶片、色块分区、观察式构图、反射和运动边缘，不规定人物、物体、地点或故事。代表图中的电车与街道只是测试主体。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把整个风格包目录交给 Agent，先读取 identity.yaml、visual-signature.yaml、reproduction.yaml、prompts、palette/palette.json 和 evaluation.yaml，再把你的主体、地点、画幅和用途编译进生成任务。

### 方式二：直接复制 Prompt

复制 prompts/base.txt，替换主体、地点和画幅；把 prompts/negative.txt 一并提交。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，提交基础 Prompt、负面约束和调色板。本仓库不托管密钥或在线生图服务。

### 方式四：本地模型 + ComfyUI

将 Prompt、调色板和复现说明接入本地模型或 ComfyUI，生成后用 evaluation.yaml 检查色彩分区、运动方向、反射关系和固定题材泄漏。
