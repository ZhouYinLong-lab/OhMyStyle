Create a new subject and composition using these observable visual decisions:
- 近距离小物与大面积空气留白并置
- 视角可以略低或略偏
- 单张画面像一组日常序列中的片段
- 淡粉、乳白、浅蓝、嫩绿和柔黄组成轻盈色组
- 高光柔和，颜色相互呼吸
- 避免过度饱和和冷暖滤镜
- 彩色胶片或柔和数字色彩响应
- 浅景深或轻微运动模糊
- 自然光近距离观察
- 窗光、阴天和清晨光线
- 光线柔和且有空气感
- 不使用硬质商业光源
- 花瓣、皮肤、水、玻璃和纸张保留细腻差异
- 不过度锐化
- 细颗粒或轻微柔化
- 画面边缘不做复古脏污
- 诗意来自尺度、光线和偶然联系
- 不是甜美滤镜或装饰静物
- 不复制具体作品和序列
Keep the medium, lighting, palette roles, surface behavior, and edge language coherent. Do not copy any reference work, named character, location, logo, text, or exact arrangement.
