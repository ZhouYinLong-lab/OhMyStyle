# Comparison assets

- `legacy.png`: the multi-activity park scene compiled with the existing package and no art direction.
- `direction.png`: the same subject rendered with `bruegel-micro-actions-landscape-route`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler jobs.
- `generation-prompts.md`: prompts, visual review, and limitations.

These are anonymous generated demonstrations, not copies of *The Harvesters* or another Bruegel work. Review whether the path links the different user-requested activities across foreground, middle distance, and background, while keeping their scale and action cues legible.

The direction image makes the three activity stations and their shared S-shaped route more explicit, though the legacy image already has a route. This is one image-to-image probe, so repeatability remains untested; see `generation-prompts.md` for the review.
