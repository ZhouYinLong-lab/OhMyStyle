# Visual comparison

- `legacy.png`: the broad Kandinsky package treatment applied to a user-requested open-center abstraction.
- `direction.png`: an edit using `kandinsky-open-center-orbital-tension`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler outputs for the base and selected direction.
- `generation-prompts.md`: prompts, observations, source boundary, and review limitations.

Both samples use the same ivory ground, oil-painted surface, cobalt/red/ochre/black palette, abstract geometry, and framing. The direction edit establishes a dominant incomplete ring around a broad quiet center and shifts the heavier geometric marks to one side. It remains experimental; this pair does not show how the direction responds to other palettes, aspect ratios, or user-requested shapes.
