# Generation prompts and visual review

## Shared subject

Exactly three fully clothed adult friends pause in conversation on a curving garden path beneath leafy trees in bright midday light. Keep distinct faces, natural gestures, and a horizontal 16:9 frame.

## Base package image

Use Renoir's broad package treatment: bright outdoor light, warm skin, broken color notes across foliage, clothes, and ground, soft edges, and a calm social feeling. This image does not load the optional art direction.

## Direction image

Edit the base image while preserving the three people, their expressions, gestures, clothing, position, path, tree canopy, camera, and painterly style. Reduce bright flecks in the foliage; place a few stronger, irregular color touches on selected clothing planes and patches of path. Keep eyes, noses, and mouths clear, and leave most surfaces in their local colors.

## Review

- **Subject preservation:** both images contain the same three distinct, fully clothed adults with the same interaction and positions.
- **Visible rule:** the base image spreads bright broken notes across the group and background. In the direction image the tree canopy is darker and quieter, while the strongest flecks appear on sleeves, shoulders, skirts/trousers, and the path; facial features remain readable.
- **Remaining limitation:** the direction image still has some incidental highlights in the foliage and clothing; exact light-patch placement is not deterministic.
- **Method:** the direction sample is an image-to-image edit to hold the scene constant. It does not prove repeatability across independent generations, models, or different group compositions. Formal visual review stays pending.

## Source boundary

The [Musée d'Orsay collection record for *La Balançoire*](https://www.musee-orsay.fr/en/artworks/la-balancoire-1096) describes filtered sunlight rendered with light-color touches, especially on clothing and the ground. This package extracts that placement observation only; it does not use the work's image as a generation input or copy its swing, figures, or composition.
