# Visual comparison

- `legacy.png`: the broad Titian package treatment applied to the requested pear, cloth, and wall.
- `direction.png`: an edit using `titian-adjacent-color-reflection`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler outputs for the base and selected direction.
- `generation-prompts.md`: prompts, observations, source boundary, and review limitations.

Both images preserve one red pear, blue wool cloth, warm ochre wall, side light, framing, and layered oil surface. The direction edit adds a small cool note at the pear's shadow-facing edge and a warm reflection on one cloth fold near contact. Local colors and material boundaries remain legible. The direction remains experimental pending tests with other materials and palettes.
