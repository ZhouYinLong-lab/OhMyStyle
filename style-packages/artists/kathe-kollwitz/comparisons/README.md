# Comparison assets

- `legacy.png`: generated fictional two-person crate-lifting scene using the existing package direction.
- `direction.png`: image-guided edit with the optional compressed figure-group direction.
- `legacy-job.json` and `direction-job.json`: compiled prompts and review metadata for inspecting the two paths.
- [`generation-prompts.md`](generation-prompts.md): prompt text, observed changes, and limitations.

The images are demonstrations, not historical source material or proof of cross-subject quality. The edit changes some object and clothing details; this is recorded as a limitation.
