# Visual comparison

- `legacy.png`: the broad Rembrandt package treatment applied to a requested hand-object portrait.
- `direction.png`: an edit using `rembrandt-hand-object-light-chain`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler outputs for the base and selected direction.
- `generation-prompts.md`: prompts, observations, source boundary, and review limitations.

Both images preserve the same adult, dark sweater, brass key, table lamp, framing, and warm palette. The direction edit lowers the lamp's intensity slightly and concentrates a small warm contact highlight on the fingers and key while keeping the face primary. The difference is subtle because the base package already emphasizes faces and hands; the direction remains experimental.
