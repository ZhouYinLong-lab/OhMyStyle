# Generation prompts and visual review

## Shared subject

One anonymous adult in a plain dark sweater quietly examines a small brass key held between the fingers near a single shaded table lamp. One visible face and clear hand-object contact; intimate horizontal 16:9 portrait.

## Base package image

Use the broad Rembrandt package treatment: warm dark ground, one dominant warm light source, psychological quiet, soft transitions on the face, readable hands, layered oil paint, selective tactile highlights, and open chromatic shadows. This sample does not load the optional art direction.

## Direction image

Edit the same oil portrait, preserving the same adult, face, sweater, hands, brass key, lamp, composition, and warm dark room. Refine only the focal light chain: lower the lamp's brightest area slightly; keep the face softly luminous; place a small warm highlight where the fingers contact the key and a restrained brass reflection along one edge of the key. Let hand, contact point, and object form one readable path of attention, with the key remaining secondary to the person. Open nearby shadows with warm detail. Add no object, symbol, glow, extra light source, or text.

## Review

- **Subject preservation:** both images show one adult, the same key, hands, lamp, room, and framing.
- **Visible rule:** the direction edit slightly restrains the lamp and sharpens the warm contact highlight where fingers meet brass.
- **Remaining limitation:** the base image already has a clear face-hand-key light path, so the outcome is a subtle refinement. The edit also alters small paint details and is not a controlled lighting comparison. Formal visual review stays pending.
- **Method:** image-to-image edit keeps scene and framing close but does not prove repeatability across independent generations or models.
