Create a new subject and composition using these observable visual decisions:
- 画面大多由单一网格或平行线系统控制
- 留白和边缘比例十分重要
- 局部偏移产生手工呼吸感
- 灰白、淡粉、浅蓝、米黄和柔灰组成低对比色组
- 颜色变化细微且不脏
- 不加入强烈焦点色
- 铅笔或细线与薄层丙烯/油彩
- 手工绘制的重复结构
- 平静哑光表面
- 均匀漫射光
- 不使用戏剧阴影或镜面高光
- 表面微差由细线和颜料层表达
- 纸、画布和薄颜料的轻微吸收感
- 不做玻璃质感
- 纹理极少但不完全无纹理
- 线条粗细有微小变化
- 克制、重复和非机械的精度同时存在
- 安静来自比例而非空白模板
- 不复制原作网格
