# Visual comparison

- `legacy.png`: the standard Sofonisba Anguissola package treatment applied to a user-defined group portrait.
- `direction.png`: an edit using `anguissola-shared-action-portrait-focus`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler outputs for the base and selected direction.
- `generation-prompts.md`: prompts, observations, source boundary, and review limitations.

Both samples show the same three adult colleagues, contemporary clothing, folded map, pointing gesture, and quiet room. The direction edit tightens the crop around the faces, pointing hand, and map, while reducing the room's presence. It remains experimental; the samples share much of the same staging, and the direction needs review with different group sizes and activities.
