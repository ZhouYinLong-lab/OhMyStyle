# 新旧架构视觉对照

| 旧版包默认规则 | 新版方向规则 |
|---|---|
| ![旧版样图](legacy.jpg) | ![新方向样图](direction.jpg) |

- **同一输入主题：** `A repairer lifting a broken pocket watch under one overhead work lamp`
- **任务记录：** [旧版编译任务](legacy-job.json)、[新版方向编译任务](direction-job.json)。
- **人工复核：** 两图都表现修表匠在单盏顶灯下查看破损怀表。旧版把人物、工作台和高举的怀表放在中景；新版改成更近的手部特写，灯光集中在脸、手和打开的表壳，周围工具与背景沉入暗部。修理动作及单盏强光仍可辨，未见新增叙事主体。新版更明确地突出身体动作和金属焦点，符合近距离调度与定向明暗规则；但景别变化显著，单样本不足以证明稳定性。
- **限制：** 两版来自独立生图调用，没有固定随机种子，不能单独证明差异由架构规则造成，也不能证明规则跨题材稳定。包状态继续保持 `experimental`。
