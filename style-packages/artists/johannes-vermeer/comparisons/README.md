# Comparison assets

- `legacy.png`: independently generated fictional townscape using the established package style direction.
- `direction.png`: image-guided edit of the same generated sample using the optional cityscape art direction.
- `legacy-job.json` and `direction-job.json`: compiled text jobs for inspecting legacy and v2 rules.
- [`generation-prompts.md`](generation-prompts.md): sample prompts, observed changes, and limitations.

The images are demonstrations, not source artworks or proof of cross-subject quality. Their generation path is documented because the edited output does not preserve every architectural detail exactly.
