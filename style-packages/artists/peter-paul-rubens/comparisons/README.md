# Comparison assets

- `legacy.png`: the two-dancer rehearsal scene rendered with the existing Rubens package and no art direction.
- `direction.png`: the same user-requested scene rendered with `rubens-diagonal-selective-light`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler jobs.
- `generation-prompts.md`: prompts, visual review, and limitations.

These are anonymous demonstrations, not copies of *The Fall of Phaeton*. Compare how the directional light travels across the figures, which planes it catches, and how much colored shadow remains.

The direction image makes the upper-right light beam and selective highlights more pronounced. Both samples remain smoother and more photographic than the oil package target; this single edited pair is not repeatability evidence. See `generation-prompts.md` for the full review.
