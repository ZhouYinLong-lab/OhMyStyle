## 简介

本包提取索罗亚户外油画中可观察、可迁移的视觉方法：强烈日光如何建立明暗和色彩关系，水面、浅色布料与地面如何把环境色反射进阴影，以及快速、有方向的笔触如何同时描绘形体和运动。高明度与鲜明色彩仍受整体明度组织约束，画面保持清楚的形体和即时的观察感。

它不把海滩、帆船或人物规定成默认主体。你提供什么主体和地点，风格包就尝试用这组光线、色彩和笔触决策来表现什么。

## 与相近画家区分

- **莫奈：** 更侧重空气、天气与色彩变化造成的视觉振动；本包强调强日照、反射光以及较清晰的大形和局部对比。
- **雷诺阿：** 常以柔和的人物塑形和温润肤色为重点；本包让硬朗日照、白色高光和环境反射参与结构。
- **梵高：** 以情绪化轮廓和节奏性笔触推动画面；本包的笔触主要沿着水流、布褶、叶片和形体转折工作。
- **透纳：** 常让天气与氛围溶解边界；本包保留可读的形体，以直接日光和反射色表现户外空气。

## 包内文件

- `identity.yaml`：范围、主体开放策略和排除项
- `visual-signature.yaml`：跨主题保持的视觉特征
- `reproduction.yaml`：从大色块到局部笔触的构建顺序
- `prompts/base.txt`、`prompts/negative.txt`：基础提示与负面约束
- `palette/palette.json`：颜色角色与色值
- `evaluation.yaml`：生成后的风格和主体检查
- `references/manifest.csv`、`provenance.yaml`：博物馆与美术馆来源、权利边界
- `examples/generated/`：仅本地保留、尚未审核的候选图；PNG 候选默认不进入版本库

## 参考依据与权利

参考清单链接到伦敦国家美术馆、普拉多博物馆和索罗亚博物馆的资料，用于研究户外绘画、强光、反射色、水面处理与构图裁切。本仓库不收录这些机构的原作图像。

代表图是通过图像生成工具制作的匿名新场景，不是索罗亚原作、复刻或授权作品，也不暗示与艺术家或博物馆存在合作关系。

## 使用

将 `{SUBJECT}`、`{LOCATION}` 和 `{SUBJECT_ACTION}` 替换为你的需求，并把基础提示、负面约束与调色板一并交给图像工作流。风格包控制媒介和视觉处理，不应擅自增加海滩、船只、帆布或固定叙事。

每次生成后，按 `evaluation.yaml` 检查主体是否按要求呈现、日光和反射色是否参与形体塑造，以及笔触是否沿着材料和运动方向组织。不要只看颜色是否明亮。
