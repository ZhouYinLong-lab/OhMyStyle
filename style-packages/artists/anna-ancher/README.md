# Anna Ancher — demo package

This package models a period-and-medium profile of Anna Ancher's painting,
especially her attention to northern light, domestic interiors, simplified
forms, and restrained but deliberate color. It is an analysis package, not a
copy of any specific painting.

The anonymous prompt in `prompts/base.txt` intentionally omits the artist's
name. The name is used for catalog identity and provenance; the reproduction
test uses observable traits only.
