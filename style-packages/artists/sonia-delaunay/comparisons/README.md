# Visual comparison

- `direction.png`: the same base image edited with `delaunay-seam-aware-garment-color-rhythm`.

The direction edit reshapes color blocks around the garment panels and keeps each pocket's pattern within its pocket boundary. The rule remains experimental pending independent generations across other garment types and materials.
