## 简介

这个包提取游移线条、半透明色块、符号化形体、浅空间和轻盈的平面节奏。它适合让主体保留一部分现实轮廓，同时进入更像音乐或手稿的视觉秩序。

它不规定鱼、天使、字母、风景或任何固定符号。包负责线、色彩、表面和空间关系，新的主题仍由使用者决定。

## 策展短评

克利的画面常常像一个还在形成的世界：线条先走出去，色块随后把它接住，某些形体像符号，却没有被解释成单一答案。代表图选择了一个带有观察意味的场景，但真正值得保留的是线条和色彩之间那种轻微、灵活的协商，而不是海岸或建筑本身。

## 主体独立性

你的主题、人物、物体、地点和叙事优先。本包只负责绘画媒介、线条、色块、浅空间、纸面和象征性处理。代表图中的观测站与海岸只是示例，不会自动出现在新的生成结果里。

## 使用前先看

- `identity.yaml`：范围与排除项
- `visual-signature.yaml`：换主体后仍应保留的视觉特征
- `reproduction.yaml`：媒介、材料和构建顺序
- `prompts/base.txt`、`prompts/negative.txt`：基础约束
- `palette/palette.json`：色彩角色
- `evaluation.yaml`：生成后的检查标准
- `references/manifest.csv`、`provenance.yaml`：来源与权利边界

## 来源与版权

收藏和展览资料只用于研究可观察特征。外部作品及其图像权利仍归原权利人所有；本包不捆绑外部作品，也不复制某件作品的构图、符号或文字。代表图是新的匿名场景，不代表与艺术家或机构存在合作、授权或背书关系。

来源： [保罗·克利中心收藏](https://www.zpk.org/en/collection)。详细边界见 [`provenance.yaml`](provenance.yaml)、[`references/manifest.csv`](references/manifest.csv) 和仓库根目录的 [`NOTICE`](../../../NOTICE)。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录上传给 Agent，或提供本地路径，并告诉它：先读取身份、视觉签名、复现说明、Prompt、调色板和评估文件，再把你的主题编译成完整 Prompt。要求它只使用包中的线条、色块和浅空间规则，不强行加入鱼、字母或风景，并在生成后按 `evaluation.yaml` 检查。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换主题、地点和画幅；把 `prompts/negative.txt` 一并作为负面约束。需要更稳定时，同时参考视觉签名和调色板。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，再提交基础 Prompt、负面约束、调色板和必要的参考清单。本仓库不托管密钥，也不提供在线生图服务。

### 方式四：本地模型 + ComfyUI

把基础 Prompt 和负面约束接入本地模型或 ComfyUI 工作流，按复现说明设置线条、透明色块、纸面和浅空间，生成后用 `evaluation.yaml` 复核。

模型权重、密钥和生成图片由使用者自行管理。参考资料用于理解特征，不用于复制原作。
