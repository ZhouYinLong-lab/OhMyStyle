# Visual comparison

- `legacy.png`: the base collage package's continuous three-storefront scene.
- `direction.png`: an edit using `bearden-connected-street-vignettes`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler jobs.
- `generation-prompts.md`: prompts, observations, and review limits.

Both images contain the same fictional bakery, bicycle repair shop, bookshop, two pedestrians, and sidewalk. The direction edit separates the three fronts into offset paper-cut vignettes while keeping the sidewalk as a continuous reading path. This is a same-image edit probe, not evidence of cross-subject repeatability; review remains experimental.
