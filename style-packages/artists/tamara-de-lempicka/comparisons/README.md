# Visual comparison

- `legacy.png`: the broad Tamara de Lempicka package treatment applied to a polished brass vessel.
- `direction.png`: an edit using `lempicka-polished-object-facets`.
- `legacy-job.json` and `direction-job.json`: provider-neutral compiler outputs for the base and selected direction.
- `generation-prompts.md`: prompts, observations, source boundary, and review limitations.

Both samples keep the same unbranded vessel, stepped stone plinth, geometric background, palette, and framing. The direction edit replaces smooth reflections with a few broad facets that follow the vessel's neck, shoulder, belly, and base, making the material feel more painted and less like a product rendering. Formal visual review stays pending; other metal and stone forms still need testing.
