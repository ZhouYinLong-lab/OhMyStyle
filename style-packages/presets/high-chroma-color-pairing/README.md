# High-Chroma Color Pairing

这是一个可迁移的“撞色”视觉预设包，不是某一位艺术家、摄影师或历史流派的仿作包。

它把你提供的花卉作品和色卡截图当作**色彩参考**，提炼出可复现的结构：一组高纯度主色与反向色形成视觉张力，再由浅色或深色中性背景提供呼吸空间。花卉、花瓶和静物只是参考中的内容，不是本包的固定题材。

## 包含的规则

- 从互补、近互补或强冷暖关系中选择一组主色对。
- 让一个颜色成为主色块，另一个颜色成为明确的反色块，而不是平均撒满画面。
- 使用浅灰、奶油色、雾灰或深海军蓝等中性地面稳定画面。
- 保留清楚的轮廓、物质感和留白，避免用全局滤镜把所有颜色染脏。
- 允许摄影、绘画、插画、海报和产品陈列使用同一套色彩逻辑。

## 参考与版权处理

仓库只记录用户提供的来源链接和从截图中读取的色值，不复制或重新分发 Bilibili 截图，也没有把未经授权的参考图放入 Git 历史。参考清单使用 `link_only` 状态；后续如要下载作品图片，必须先逐张确认来源、许可和再分发条件。

## 使用边界

本包不等于“彩虹色”、随机霓虹色、某个花艺师的个人风格，也不要求生成花朵或花瓶。判断是否命中本包，应优先检查色彩对的识别度、面积层级、背景反差和主体可读性。

## 文件导览

- `palette/palette.json`：从用户参考色卡整理的配色对。
- `visual-signature.yaml`：视觉不变量和构图约束。
- `reproduction.yaml`：生成或创作时的选择顺序与面积比例。
- `prompts/`：匿名化基础提示词和排除条件。
- `references/manifest.csv`：来源链接与权利状态。
- `examples/`：接受与拒绝样例的评估位置；当前没有上传生成图。
