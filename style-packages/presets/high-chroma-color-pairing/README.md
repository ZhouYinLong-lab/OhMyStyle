# High-Chroma Color Pairing

这是一个可迁移的“撞色”视觉预设包，不是某一位艺术家、摄影师或历史流派的仿作包。

它把你提供的花卉作品和色卡截图当作**色彩参考**，只提炼颜色并置、面积分配、明度关系和材质保真度。花卉、花瓶和静物只是参考载体，不是本包的题材方向；同一套规则必须能迁移到海报、时装、人像、产品、室内和自然景观。

## 包含的规则

- 从互补、近互补或强冷暖关系中选择一组主色对。
- 让一个颜色成为主色块，另一个颜色成为明确的反色块，而不是平均撒满画面。
- 使用浅灰、奶油色、雾灰或深海军蓝等中性地面稳定画面。
- 保留清楚的轮廓、物质感和留白，避免用全局滤镜把所有颜色染脏。
- 允许摄影、绘画、插画、海报、产品、室内和景观使用同一套色彩逻辑。

## 参考与版权处理

经用户明确要求，仓库现在保存了压缩后的 WebP 参考图：6 张花卉画面放在 `references/primary/`，7 张色卡细节放在 `references/details/`。它们只承担颜色参考作用，并均标记为用户授权上传的参考截图；这不等同于 Bilibili 视频作者或画面原作者授予的开放许可，因此后续公开再分发时仍应逐张确认来源、许可和平台规则。

## 使用边界

本包不等于“彩虹色”、随机霓虹色、某个花艺师的个人风格，也不要求生成花朵或花瓶。判断是否命中本包，应优先检查色彩对的识别度、面积层级、背景反差、主体可读性以及不同材质对指定颜色的保持能力。

## 文件导览

- `palette/palette.json`：从用户参考色卡整理的配色对。
- `visual-signature.yaml`：视觉不变量和构图约束。
- `reproduction.yaml`：生成或创作时的选择顺序与面积比例。
- `prompts/`：匿名化基础提示词和排除条件。
- `prompts/benchmarks/`：7 个跨题材测试 Prompt，用于检查系统是否脱离花卉题材仍能稳定复现撞色逻辑。
- `references/manifest.csv`：来源链接与权利状态。
- `examples/`：接受与拒绝样例的评估位置；当前没有上传生成图。
