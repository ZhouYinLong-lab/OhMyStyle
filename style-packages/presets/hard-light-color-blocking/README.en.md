## Overview

This independent package turns public research and observable decisions about medium, composition, color, light, material, and texture into executable constraints for new subjects. It is not intended to copy a specific work.

## Style focus

Organizes images through hard directional light, clear shadows, separated color planes, and material differences without pretending to be the style of a particular photographer or subject.

## Use only this package

1. Download this directory and read `identity.yaml`, `visual-signature.yaml`, and `reproduction.yaml`.
2. Open `prompts/base.txt` and replace the subject with your own; negative constraints are in `prompts/negative.txt`.
3. Paste the prompt into an image platform or import it with the references and palette into a local model and ComfyUI.
4. Use references to understand observable traits; do not copy a source work’s exact composition, person, text, trademark, or logo.
