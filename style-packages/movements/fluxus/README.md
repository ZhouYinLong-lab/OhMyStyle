# 激浪派

[English](README.en.md)

![激浪派代表图](gallery-16x9.jpg)

> **分类：** 艺术流派与历史时期  
> **媒介领域：** 混合媒介  
> **目录：** `style-packages/movements/fluxus`

## 简介

这个包提取事件性、日常材料、简单行动、开放解释和反精致的呈现方式。它可以让一张图像像某个动作发生过的记录，也可以只留下一个没有被解释完的视觉关系。

它不要求每次出现说明卡、表演者、舞台、纸张或某一组道具。你的主题仍然优先，激浪派只提供一种把普通事物变成视觉事件的组织方法。

## 策展短评

激浪派让我感兴趣的地方，是它不急着把“作品”做得完整。一个很小的动作、一件不起眼的材料，甚至一个没有结果的安排，都可以把观看从物品本身推向“刚刚发生了什么”。使用这个包时，重要的不是增加奇怪道具，而是给画面留下一条可追溯、又不必被解释到底的行动线索。

## 主体独立性

你的主题、人物、物体、地点和叙事优先。本包只负责事件逻辑、构图、材料证据、光线、表面和开放程度。代表图中的桌面、纸张和杯子只是示例，不会自动出现在新的生成结果里。

## 使用前先看

- `identity.yaml`：范围与排除项
- `visual-signature.yaml`：换主体后仍应保留的视觉特征
- `reproduction.yaml`：媒介、材料和构建顺序
- `prompts/base.txt`、`prompts/negative.txt`：基础约束
- `palette/palette.json`：色彩角色
- `evaluation.yaml`：生成后的检查标准
- `references/manifest.csv`、`provenance.yaml`：来源与权利边界

## 来源与版权

展览和博物馆页面只用于研究可观察特征。外部作品及其图像权利仍归原权利人所有；本包不捆绑外部作品，也不复制某件作品的构图、文字或标志。代表图是新的匿名场景，不代表与相关艺术家、流派或机构存在合作、授权或背书关系。

来源： [现代艺术博物馆《艺术与生活的边界》](https://www.moma.org/calendar/galleries/5121)。详细边界见 [`provenance.yaml`](provenance.yaml)、[`references/manifest.csv`](references/manifest.csv) 和仓库根目录的 [`NOTICE`](../../../NOTICE)。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录上传给 Agent，或提供本地路径，并告诉它：先读取身份、视觉签名、复现说明、Prompt、调色板和评估文件，再把你的主题编译成完整 Prompt。要求它只使用包中的事件和视觉规则，不强行加入说明卡、表演者或固定道具，并在生成后按 `evaluation.yaml` 检查。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换主题、地点和画幅；把 `prompts/negative.txt` 一并作为负面约束。需要更稳定时，同时参考视觉签名和调色板。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，再提交基础 Prompt、负面约束、调色板和必要的参考清单。本仓库不托管密钥，也不提供在线生图服务。

### 方式四：本地模型 + ComfyUI

把基础 Prompt 和负面约束接入本地模型或 ComfyUI 工作流，按复现说明设置行动线索、材料、光线和开放空间，生成后用 `evaluation.yaml` 复核。

模型权重、密钥和生成图片由使用者自行管理。参考资料用于理解特征，不用于复制原作。
