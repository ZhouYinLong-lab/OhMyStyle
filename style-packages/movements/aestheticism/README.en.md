## Overview

Aestheticism treats painting, objects, space, material, and pattern as one integrated environment, often summarized by “art for art’s sake.” This package extracts decorative unity, sensuous surface, controlled asymmetry, and pattern-scale relationships. It is not a Victorian room or a single ornamental motif.

## Curatorial note

The pleasure comes from letting subject and background complete each other instead of competing for attention. An ordinary object can become refined when its color, material, edge, and surrounding space form a coherent rhythm. Do not pile on expensive decoration; establish the whole visual cadence first.

## Subject independence

This package controls visual treatment, not the object, place, pattern, or historical story. Peacocks, Japanese objects, floral wallpaper, and Victorian interiors are not default requirements.

## Use only this package

1. **Image-capable Agent:** upload this directory. Ask the Agent to read the rules, confirm your subject, generate, and review against `evaluation.yaml`.
2. **Copy the prompts:** replace subject, location, aspect ratio, and purpose in `prompts/base.txt`, then submit `prompts/negative.txt`.
3. **Use your own API:** configure your API key and submit the prompt, negative constraints, palette, and reference links.
4. **Local model and ComfyUI:** connect the prompts, use the reproduction notes for pattern, material, color, and light, then review the result.

References are for observable traits only. Do not copy a source work’s composition, figures, text, trademark, or logo.
