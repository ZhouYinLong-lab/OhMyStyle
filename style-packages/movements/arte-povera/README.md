> **分类：** 艺术流派与历史时期  
> **媒介领域：** 混合媒介  
> **目录：** `style-packages/movements/arte-povera`

## 简介

这个包提取非贵重材料、粗粝表面、临时平衡、自然变化和材料之间的张力。它让画面关注“东西是怎么存在的”，而不只是把结果整理得漂亮。

它不要求每次出现泥土、石头、麻布、树枝、铁丝或展厅。你的主题仍然优先，包只负责材料意识、表面、空间和完成度。

## 策展短评

贫穷艺术最有力量的地方，是材料不再只是承载形式的配角。重量、脆弱、腐蚀、摩擦和临时连接都可以成为画面的一部分。代表图用了很直观的原生材料，但真正想保留的是那种不把痕迹擦掉的态度：让材料自己说出时间和过程。

## 主体独立性

你的主题、人物、物体、地点和叙事优先。本包只负责材料行为、粗粝表面、临时关系、空间张力和自然色彩。代表图中的装置和材料只是示例，不会自动出现在新的生成结果里。

## 使用前先看

- `identity.yaml`：范围与排除项
- `visual-signature.yaml`：换主体后仍应保留的视觉特征
- `reproduction.yaml`：媒介、材料和构建顺序
- `prompts/base.txt`、`prompts/negative.txt`：基础约束
- `palette/palette.json`：色彩角色
- `evaluation.yaml`：生成后的检查标准
- `references/manifest.csv`、`provenance.yaml`：来源与权利边界

## 来源与版权

博物馆术语和收藏资料只用于研究可观察特征。外部作品及其图像权利仍归原权利人所有；本包不捆绑外部作品，也不复制某件作品的构图、材料组合或标志。代表图是新的匿名场景，不代表与相关艺术家、流派或机构存在合作、授权或背书关系。

来源： [现代艺术博物馆的贫穷艺术术语页](https://www.moma.org/collection/terms/arte-povera)。详细边界见 [`provenance.yaml`](provenance.yaml)、[`references/manifest.csv`](references/manifest.csv) 和仓库根目录的 [`NOTICE`](../../../NOTICE)。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录上传给 Agent，或提供本地路径，并告诉它：先读取身份、视觉签名、复现说明、Prompt、调色板和评估文件，再把你的主题编译成完整 Prompt。要求它只使用包中的材料与表面规则，不强行加入泥土、石头或展厅，并在生成后按 `evaluation.yaml` 检查。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换主题、地点和画幅；把 `prompts/negative.txt` 一并作为负面约束。需要更稳定时，同时参考视觉签名和调色板。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，再提交基础 Prompt、负面约束、调色板和必要的参考清单。本仓库不托管密钥，也不提供在线生图服务。

### 方式四：本地模型 + ComfyUI

把基础 Prompt 和负面约束接入本地模型或 ComfyUI 工作流，按复现说明设置材料、接触关系、粗糙表面和空间张力，生成后用 `evaluation.yaml` 复核。

模型权重、密钥和生成图片由使用者自行管理。参考资料用于理解特征，不用于复制原作。
