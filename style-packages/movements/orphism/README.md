# 奥菲主义

[English](README.en.md)

![奥菲主义代表图](gallery-16x9.jpg)

> **分类：** 艺术流派与历史时期  
> **媒介领域：** 早期现代主义色彩抽象绘画  
> **目录：** `style-packages/movements/orphism`

## 简介

奥菲主义把色彩、圆弧和节奏当作画面结构来使用。它不依赖一个必须被讲述的故事，也不要求每张图都出现太阳、星球或唱片。这个包更关心颜色怎样彼此推动、平面怎样相互咬合，以及抽象程度如何服务于用户的主体。

## 策展短评

我喜欢奥菲主义的地方，是它让“光”不再只来自一盏灯。相邻的蓝和橙、红和绿可以互相抬高，圆弧和扇面则像音乐里的节拍，带着视线穿过画面。使用时不必把所有东西都拆成几何图形；保留主体，再让色彩关系和局部节奏改变它的观看方式，通常更耐看。

## 主体独立性

本包只决定色彩对比、圆弧节奏、平面边界和有限绘画质感，不规定太阳、星球、窗户、唱片、宇宙或任何固定物体。代表图中的抽象城市剖面只是测试主体，新的生成应以用户需求为准。

## 来源与版权

研究入口为[现代艺术博物馆的奥菲主义术语条目](https://www.moma.org/collection/terms/orphism)，并参考[罗伯特·德洛内的作品档案](https://www.moma.org/collection/works/78302)。仓库不打包外部作品；代表图是新的匿名图像，不是具体原作，也不表示合作、授权或背书关系。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录交给 Agent，让它先读取 `identity.yaml`、`visual-signature.yaml`、`reproduction.yaml`、`prompts/`、`palette/palette.json` 和 `evaluation.yaml`，再编译你的主体、画幅和用途。生成后检查颜色是否承担结构，主体是否仍然可辨，以及是否出现了不必要的固定意象。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换 `{{SUBJECT}}`、`{{ASPECT_RATIO}}` 和 `{{USE_CASE}}`；把 `prompts/negative.txt` 一并提交给支持负面 Prompt 的平台。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，提交基础 Prompt、负面约束和调色板。本仓库不托管密钥或在线生图服务。

### 方式四：本地模型 + ComfyUI

将 Prompt、调色板和复现说明接入本地模型或 ComfyUI，生成后用 `evaluation.yaml` 复核，不要把代表图的城市剖面当成默认主体。
