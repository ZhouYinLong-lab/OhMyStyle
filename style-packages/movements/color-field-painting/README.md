> **目录：** `style-packages/movements/color-field-painting`

## 简介

色域绘画把大面积、低调制的颜色当作画面本身的结构。观看者不是先寻找一个中心物体，而是在色域的比例、边界和邻接关系里感受空间与情绪。这个包提取色面的持续性和安静重量；如果用户给了具体主体，色域会围绕、简化或托住它，不会强制把主体消解成抽象图形。

## 策展短评

它最打动我的地方，是画面可以很少，却并不空。颜色铺开以后，比例和边界会慢慢变成一种空间感。使用时不必把“大色面”理解成几个规整矩形，也不必急着加纹理；先决定哪一种颜色需要占据时间和注意力，画面通常就已经有了自己的节奏。

## 主体独立性

本包只决定大色域、颜色比例、边界、留白和低密度表面，不规定矩形、圆形、地平线、符号或纯抽象输出。代表图是非具象色面测试，新的生成仍应以用户主体和用途为准。

## 来源与版权

研究入口为[现代艺术博物馆的色域绘画术语条目](https://www.moma.org/collection/terms/color-field-painting)。仓库不打包外部作品；代表图是新的匿名抽象图像，不是具体原作，也不表示合作、授权或背书关系。

## 只使用此包

### 方式一：交给有生图能力的 Agent

把本目录交给 Agent，让它先读取 `identity.yaml`、`visual-signature.yaml`、`reproduction.yaml`、`prompts/`、`palette/palette.json` 和 `evaluation.yaml`，再编译你的主体、画幅和用途。生成后检查色域是否连续、主体是否保留，以及画面是否被无关纹理填满。

### 方式二：直接复制 Prompt

打开 `prompts/base.txt`，替换 `{{SUBJECT}}`、`{{ASPECT_RATIO}}` 和 `{{USE_CASE}}`；把 `prompts/negative.txt` 一并提交给支持负面 Prompt 的平台。

### 方式三：配置 API Key 后提交生成

在你自己的生图平台或编译工具中配置 API Key，提交基础 Prompt、负面约束和调色板。本仓库不托管密钥或在线生图服务。

### 方式四：本地模型 + ComfyUI

将 Prompt、调色板和复现说明接入本地模型或 ComfyUI，生成后用 `evaluation.yaml` 复核，不要把代表图的抽象色面当成唯一主体。
