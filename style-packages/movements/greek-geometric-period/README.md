# Greek Geometric Period — demo package

This package models the visual grammar of early Greek Geometric art as an
observable system: horizontal registers, angular silhouettes, repeated motifs,
and narrative compression. It is not a request to copy a named vessel or
museum object.

The anonymous prompt deliberately omits the package name. Reference artworks
are recorded as links only; generated material belongs in `examples/generated/`
and must remain marked for human review.
