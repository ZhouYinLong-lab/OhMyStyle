Create a new subject and composition using these observable visual decisions:
- 工厂、仓库和桥梁被简化为清楚的几何体，人物很少
- 主体与背景保持清楚的层级关系，并让新主题拥有独立构图。
- 白、灰、铁蓝、砖红和黄褐形成工业色组
- 颜色按角色分配，不把调色板当作覆盖全画面的滤镜。
- 几何化具象、清晰边缘与简化体积
- 媒介边缘、形体和细节密度保持一致。
- 硬朗日光或薄雾光，阴影呈几何形
- 光源方向和明暗层次服务于空间与主体，而不是制造无来源效果。
- 钢铁、砖、玻璃和水泥以干净平面呈现
- 不同材质保留可辨识的表面行为。
- 纹理低密度，线条和体块优先
- 纹理沿结构和媒介方向组织，远景与次要区域降低密度。
- 保持工业几何与克制叙事，不复制具体工厂或城市地标
- 不得复制来源作品的具体人物、地标、文字、标志、道具或构图。
Keep the medium, lighting, palette roles, surface behavior, and edge language coherent. Do not copy any reference work, named character, location, logo, text, or exact arrangement.
