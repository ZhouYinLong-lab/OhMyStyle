# Surreal Megatype Dossier Collage

[English](README.en.md)

![Surreal Megatype Dossier Collage 代表图](preview-16x9.jpg)

## 简介

让巨大白色填充与描边字位于中央超现实照片剪裁雕塑之后，再用技术小字、序列号、分栏、警示标签、星体符号和粗旧印刷颗粒框住深黑画面。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/surreal-megatype-dossier-collage.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
