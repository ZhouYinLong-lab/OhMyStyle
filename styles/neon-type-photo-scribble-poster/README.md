[English](README.en.md)

![Neon Type Photo Scribble Poster 代表图](preview-16x9.jpg)

## 简介

A high-impact event poster system built from a toxic neon color field, huge black condensed typography, a centered documentary photo crop, and a raw white spray-marker gesture that cuts across the middle of the composition.

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/neon-type-photo-scribble-poster.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
