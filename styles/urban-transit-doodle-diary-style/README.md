# Urban Transit Doodle Diary Style

[English](README.en.md)

![Urban Transit Doodle Diary Style 代表图](preview-16x9.jpg)

## 简介

把真实公共空间抓拍当作个人视觉日记，加入大胆手绘漫画覆盖、旅行手记、饱和卡通脸和一只占据前景的大手势。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/urban-transit-doodle-diary-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
