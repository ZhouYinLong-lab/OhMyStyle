## 简介

以大胆目的地字、可爱贴纸、漫画对话框、剪裁时装照片、半调城市背景和剪贴簿式编辑布局，构成信息密度很高的日本城市旅行拼贴。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/tokyo-kawaii-travel-collage-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
