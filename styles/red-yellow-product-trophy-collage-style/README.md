## 简介

借鉴快餐广告牌的红黄块面、超大窄体字和亮面剪裁产品，把多个无品牌产品对象组装成中央冠军奖杯般的视觉符号。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/red-yellow-product-trophy-collage-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
