# Electric Blue Cutout Manga Poster Style

[English](README.en.md)

## 简介

以饱和电蓝色面、锐利白色剪纸几何、圆润模块化大字、暖橙小字和一个带夸张前景道具的赛璐璐漫画人物组成可复用海报系统。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/electric-blue-cutout-manga-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
