## 简介

以不对称技术档案侧栏、裁切并海报化的面孔、液态铬干扰、模块网格、光学图表和粗半调颗粒，组合午夜靛蓝、暖奶油、洋红、钴蓝与珊瑚色。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/retro-future-chrome-portrait-dossier.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
