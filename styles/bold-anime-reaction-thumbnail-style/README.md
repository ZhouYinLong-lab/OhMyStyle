# Bold Anime Reaction Thumbnail Style

[English](README.en.md)

![Bold Anime Reaction Thumbnail Style 代表图](preview-16x9.jpg)

## 简介

以夸张反应角色、醒目的黄色标题、硬朗黑色阴影、分屏取景、小型发光动作插图和干净赛璐璐上色，形成高冲击力动漫网页缩略图。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/bold-anime-reaction-thumbnail-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
