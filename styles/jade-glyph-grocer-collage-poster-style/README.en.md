## Overview

A sparse East Asian grocer-poster system built from warm cream paper, oversized jade-green hand-cut glyphs, pale vegetable silhouette clouds, tiny editorial headers, and one glossy produce-photo centerpiece layered over the typography.

This compatibility preset is inherited from `AI-Visual-Prompt-Cookbook`. The original attribution, file structure, and license boundaries are retained.

1. Download this directory and open `style.json` or the [copyable Prompt](../../docs/copy-prompts/jade-glyph-grocer-collage-poster-style.md).
