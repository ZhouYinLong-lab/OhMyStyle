## 简介

以黑、白、猩红三色、巨大窄体字、裁切墨线人物、编辑元数据、半调阴影、红色点色冲击图形和折叠复印纸纹理构成漫画小报。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/red-black-manga-tabloid-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
