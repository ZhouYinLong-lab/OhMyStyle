## 简介

以细密漫画墨线、巨大的奶油色有机烟云、稀疏青绿色框架、桃色皮肤或物件点缀和精确的微型城市建筑建立留白充足的插画系统。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/cream-smoke-city-manga-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
