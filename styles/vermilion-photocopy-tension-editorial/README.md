## 简介

以被巨大裁切的黑白照片、近二值复印对比、密集模拟颗粒、竖向窄体标题、注释块和一层穿过画面的朱红墨迹制造紧张的编辑海报。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/vermilion-photocopy-tension-editorial.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
