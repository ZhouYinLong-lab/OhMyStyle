# Y2K Mirror UI Scribble Collage Style

[English](README.en.md)

![Y2K Mirror UI Scribble Collage Style 代表图](preview-16x9.jpg)

## 简介

以广角闪光摄影、漂浮的桌面界面碎片、电蓝马克笔描边、手绘涂鸦字和密集模拟噪声组成混乱的个人屏幕拼贴。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/y2k-mirror-ui-scribble-collage-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
