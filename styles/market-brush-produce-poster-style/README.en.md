## Overview

A sparse fresh-market poster system with a warm ivory paper field, one oversized glossy produce hero, a smaller echo product, violent black hand-cut brush typography, thin editorial header text, and tiny bottom seal-like captions.

This compatibility preset is inherited from `AI-Visual-Prompt-Cookbook`. The original attribution, file structure, and license boundaries are retained.

1. Download this directory and open `style.json` or the [copyable Prompt](../../docs/copy-prompts/market-brush-produce-poster-style.md).
