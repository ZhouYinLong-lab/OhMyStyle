# Naive Marker PSA Poster Style

[English](README.en.md)

![Naive Marker PSA Poster Style 代表图](preview-16x9.jpg)

## 简介

用粗糙不规则马克笔轮廓、蓝边对话框文字、简化人物、扁平公共道具、粉彩纸面和警示符号，保持有意稚拙的透视和清晰的公益层级。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/naive-marker-psa-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
