# Cobalt Torn Didone Portrait Editorial

[中文](README.md)

![Cobalt Torn Didone Portrait Editorial representative image](preview-16x9.jpg)

## Overview

A sparse fashion-editorial poster system built from a warm paper field, one centered halftone portrait or sculptural subject, monumental cobalt Didone typography, an irregular horizontal torn-paper reveal, and restrained calligraphic and catalog-like corner notes.

This compatibility preset is inherited from `AI-Visual-Prompt-Cookbook`. The original attribution, file structure, and license boundaries are retained.

## Use only this preset

Choose any one of the four methods below. They are alternatives, not steps that must all be completed.

### Method 1: Give the package to an image-capable Agent

Upload the entire preset directory to an Agent that can generate images, or provide its local path, together with the following instruction:

```
Use this inherited preset to help me generate an image.

First read:
- style.json
- README.md
- preview-16x9.jpg

Extract the Prompt, variables, and constraints from style.json. Do not treat the preset name as the whole Prompt, and do not copy the preview image's exact composition, people, text, trademarks, or marks.

My generation request is:
<describe the subject, people, objects, scene, aspect ratio, and intended use>

First compile my request with the preset rules into a complete Prompt, then use your image-generation capability. After generating, check the preset traits, composition, color, material, AI artifacts, and Prompt adherence. If there are clear problems, explain them and make one targeted correction.
```

### Method 2: Copy the Prompt directly

Open `style.json`, or open the [copyable Prompt](../../docs/copy-prompts/cobalt-torn-didone-portrait-editorial-style.md), replace the subject and variables, and submit it to an image platform that supports text-to-image generation. For more consistent results, also consult the preview image and the constraint fields in this directory.

### Method 3: Configure your API key and submit a job

Configure your API key in the image platform or in your own Prompt compiler, then submit the Prompt, variables, negative constraints, and any necessary preview reference from `style.json`. Keep the API key in your own environment. This repository does not store keys, host an online generation service, or promise free quota or compatibility with any particular provider.

### Method 4: Local model + ComfyUI

Connect the Prompt and constraint fields from `style.json` to a local model or ComfyUI workflow. Use the preview image to understand observable characteristics, and use the JSON variables and composition requirements to configure the workflow. Review the result afterward and avoid copying the preview image directly.
