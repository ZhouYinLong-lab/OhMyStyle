## 简介

以酸橙绿摄影棚、毛绒吉祥物、厚重科技道具、柔软织物、半透明塑料配件、棋盘卡片、贴纸图标和粉色爆发图形，形成明亮的 3D 玩具广告。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/neon-plush-gadget-pop-3d-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
