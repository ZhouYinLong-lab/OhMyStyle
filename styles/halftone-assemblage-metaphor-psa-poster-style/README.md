## 简介

把一种材料重新排列成另一种可识别的象征轮廓，以陈旧奶油纸上的低饱和蓝绿色半调对象配合紧凑的红蓝公益标题，形成简洁的隐喻海报。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/halftone-assemblage-metaphor-psa-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
