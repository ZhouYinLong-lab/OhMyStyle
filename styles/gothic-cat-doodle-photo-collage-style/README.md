## 简介

把戏剧化真实建筑照片与扁平卡通生物覆盖层结合，再加入泡泡手写标题和松散马克笔涂鸦，形成俏皮又略带哥特气息的照片插画拼贴。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/gothic-cat-doodle-photo-collage-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
