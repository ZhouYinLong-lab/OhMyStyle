## 简介

模拟折叠大报广告：密集双语报纸字、旧白纸、黑与古金色标题、盖章标签、红色编辑侧签，以及一件压过页面前景的写实主产品。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/folded-newspaper-product-ad-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
