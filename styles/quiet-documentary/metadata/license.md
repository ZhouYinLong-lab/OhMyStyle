# Package licensing

The original documentation and metadata in this package are covered by the
repository license unless a more specific notice says otherwise.

Reference images, diagrams, swatches, and example images are separate assets.
Each asset must have a row in `sources.csv` with a source, license, and
attribution before it is committed. If those facts are unknown, do not add the
asset to the package.

This package currently contains no external raster reference or example image.
