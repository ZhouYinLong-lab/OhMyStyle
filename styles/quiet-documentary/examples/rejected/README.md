# Rejected examples

Rejected examples are useful evidence, but they must be clearly labeled and
licensed like accepted examples. Record a short sidecar explanation with one or
more reasons such as:

- `saturation_too_high`;
- `light_too_hard`;
- `composition_too_commercial`;
- `depth_of_field_too_extreme`;
- `surface_too_plastic`;
- `source_or_license_unclear`.

The package currently contains no rejected raster image. Add one only when its
source and redistribution status are recorded.
