# Accepted examples

An accepted example should demonstrate most of the following at once:

- soft available light with believable direction;
- low saturation and preserved shadow detail;
- an off-center subject with meaningful negative space;
- a 35–50 mm equivalent viewpoint or an explained exception;
- moderate depth of field rather than extreme blur;
- natural materials, skin, and environmental texture;
- no copied logo, watermark, identifiable source composition, or unlicensed
  reference material.

Use semantic names such as
`001_window-light_environmental-portrait.jpg`. Add a sidecar `.yaml` file when
the capture or generation settings need to be reproduced.
