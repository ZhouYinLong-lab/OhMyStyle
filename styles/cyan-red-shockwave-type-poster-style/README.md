# Cyan Red Shockwave Type Poster Style

[English](README.en.md)

![Cyan Red Shockwave Type Poster Style 代表图](preview-16x9.jpg)

## 简介

以青色底、超大红色块字、柠檬黄人物点缀、白色锯齿冲击波、粗红描边和旋转小字，制造介于地区旅行海报、漫画冲击图形与丝网招贴之间的平面效果。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/cyan-red-shockwave-type-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
