# Soft Analog Future Editorial Poster

[English](README.en.md)

![Soft Analog Future Editorial Poster 代表图](preview-16x9.jpg)

## 简介

以暖奶油纸、黑色 neo-grotesk 大字、严格网格、复古科技静物、浅蓝半透明界面、植物前景和细小双语信息设计融合模拟未来感。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/soft-analog-future-editorial-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
