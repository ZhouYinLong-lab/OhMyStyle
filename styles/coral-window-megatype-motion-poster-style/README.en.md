## Overview

A tactile editorial motion-poster system built from a coral-red paper field, one cool pale-blue photographic window, colossal black condensed typography that crosses the image boundary, a single isolated action subject, sparse micro-editorial labels, and a bold geometric direction symbol.

This compatibility preset is inherited from `AI-Visual-Prompt-Cookbook`. The original attribution, file structure, and license boundaries are retained.

## Use only this preset

1. Download this directory and open `style.json` or the [copyable Prompt](../../docs/copy-prompts/coral-window-megatype-motion-poster-style.md).
2. Replace the variables and subject, then paste the Prompt into an image model.
3. You may also import `style.json` and the preview image into a local model or ComfyUI workflow.
