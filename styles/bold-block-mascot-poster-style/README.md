# Bold Block Mascot Poster Style

[English](README.en.md)

![Bold Block Mascot Poster Style 代表图](preview-16x9.jpg)

## 简介

用巨大的黑色展示字、厚实的白色吉祥物、粗卡通轮廓、倾斜的青色或薄荷色面板、紧凑徽章和少量红色点缀，铺在干净的米白纸面上。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/bold-block-mascot-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
