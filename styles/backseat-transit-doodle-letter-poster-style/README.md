## 简介

以乘客座位上的真实交通照片为底，叠加中央后视人物、亮黄色剪影光圈、黄橙手绘大字、漫画放射线、紫色音乐符号和青白色云形涂鸦，形成高能量旅行海报。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/backseat-transit-doodle-letter-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
