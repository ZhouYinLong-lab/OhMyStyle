## 简介

以猩红色场、斜向块状大字、层叠照片剪影、硬图形阴影、紧凑编辑文字和受控颗粒建立速度与压力感，同时不保留原球队、标志、口号或具体场景。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/scarlet-megatype-action-collage-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
