# Electric Blue Silhouette Product Launch Style

[English](README.en.md)

![Electric Blue Silhouette Product Launch Style 代表图](preview-16x9.jpg)

## 简介

以黑色负空间、中央产品剪影、电蓝轮廓光、发光横台、柔和反射、裁切式蓝色背景字和简洁白色发布文案制造高级科技产品发布视觉。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/electric-blue-silhouette-product-launch-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
