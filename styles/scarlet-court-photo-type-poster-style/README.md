## 简介

以平涂猩红底、硬边蓝色体育照片、跨越两块区域的剪裁人物、暖奶油大字、竖向侧边小字和粗粝印刷纹理构成动作广告。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/scarlet-court-photo-type-poster-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
