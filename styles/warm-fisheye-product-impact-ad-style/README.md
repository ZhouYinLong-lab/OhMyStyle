## 简介

以超广角近景、由有纹理前景物组成的隧道、倾斜白色中文大字、暖琥珀棕对比、顶部导航小字和产品标注，模拟从零食堆中冲向观众的商业缩略图。

这是继承自 `AI-Visual-Prompt-Cookbook` 的兼容预设。本仓库保留原始归属、文件结构和许可证边界。

## 只使用此预设

1. 下载本目录，打开 `style.json` 或 [复制 Prompt](../../docs/copy-prompts/warm-fisheye-product-impact-ad-style.md)。
2. 替换变量和主题后，将 Prompt 复制到任意支持文字生图的平台。
3. 也可以把 `style.json` 和预览图导入本地模型或 ComfyUI 工作流。
