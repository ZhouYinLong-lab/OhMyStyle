# OhMyStyle

[English](README.en.md)

[![风格包](https://img.shields.io/badge/风格包-90-6C63FF)](style-packages/) [![继承预设](https://img.shields.io/badge/继承预设-110-5B8C5A)](styles/)

OhMyStyle 是一个面向生图用户的视觉风格预设库。你可以从艺术家、摄影师、艺术流派、工艺、游戏美术和原创预设中选择一个独立风格包，再把它用于自己的主题。

## 风格包画廊

主画廊只展示独立风格包。所有卡片统一使用横版 16:9 代表图，点击图片或名称进入风格包 README。

## 交叉风格功能

交叉风格不作为独立风格加入上面的主画廊。它是一种可选组合机制，可以把不同风格包分别分配给媒介、光线、色彩、前景或背景等职责。

可用模式：`stack`（分工叠加）、`blend`（加权融合）、`contrast`（区域对比）。详细规则和示例见 [交叉风格功能](style-packages/composites/README.md)。
